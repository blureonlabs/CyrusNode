# Daily Notes

> Engineering log. One file per working day. Stays short.

File name: `YYYY-MM-DD.md`.

Template:

```markdown
# 2026-06-27

## Today
- What I worked on (link to task IDs in [[../TODO]] and sprint files).
- Bugs found, ideas parked.
- Cost-per-company seen today.

## Tomorrow
- Top 1–2 things.

## Open questions
- ...
```

These notes are not part of the product. They are the operator's lab journal — useful to read back six months from now.
