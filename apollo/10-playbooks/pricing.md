# Pricing Playbook

## Anchors
- **Discovery audit**: $500 floor, $1500 ceiling. Often credited to the engagement.
- **Build engagement (V1 scope)**: $5k floor, $25k ceiling.
- **Retainer**: $1500 floor, $5000 ceiling per month.

## Choosing where to land

| Signal | Pull up | Pull down |
|---|---|---|
| Established business (≥10 years, >50 staff) | + | |
| Visible ad spend (Meta library, GA4 + GTM) | + | |
| Multiple stakeholders involved | + | |
| First-time AI buyer | | – |
| Solo founder / very small team | | – |
| Free pilot lighthouse candidate | | – – |

Pull-ups raise the floor by ~25%. Pull-downs lower by ~25%. Two compounding pulls = ~50%.

## Payment terms
- 50% on signature, 50% on launch. (V1 default.)
- Bank transfer or Stripe (USD or AED).
- For retainers: monthly in advance.

## Discounting rules
- Never discount before the prospect has objected to price.
- Never discount more than 20% off the original quote.
- Always trade discounts for scope reductions or commitments (case-study rights, testimonial, longer retainer).

## Common shapes

### Shape A — Single-build SMB
- $1000 audit + $7500 build + $1500/month retainer.
- 3–4 week build. 90-day light retainer.

### Shape B — Lighthouse pilot
- $0 audit + $0 build + case-study + testimonial agreement signed up-front.
- 6-week build. Strict scope. Success metric pre-agreed.

### Shape C — Multi-channel build
- $1500 audit + $18000 build + $3500/month retainer.
- 8 weeks. Two channels (e.g. WhatsApp + website chatbot).

## What never happens
- "Pay only if it works" gigs without a real success metric defined.
- Equity-only deals.
- Subscription-with-no-floor pricing for businesses below $1M revenue. Too risky.
